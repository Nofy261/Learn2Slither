Board = l'état complet du jeu (la réalité entière)

State = l'information visible par l'agent pour prendre une décision

	ORDRE:
State -> Choix de l'Action(explore/exploite avec Epsilon-greedy) -> Environment applique l'action -> Reward -> Nouveau State -> Update Q-value(Bellman)



Q(State, Action) = Q-value
La Q-value est : une note attribuée à une action dans une situation donnée.
Et le Q-learning consiste à améliorer ces notes au fil de l'expérience.

La méthode classique : epsilon-greedy (choisir une action pendant l'apprentissage)
 On définit une valeur: epsilon = 0.1
   ->Ce qui signifie : 10% du temps → exploration ET 90% du temps → exploitation


Avant de choisir une action , on fait un tirage aleatoire :
si random < epsilon -> On Explore
sinon -> On exploite 


En termes très simples
Le cerveau de l'agent contient deux mécanismes :
1. Mémoire = Q-table: Elle stocke ce qu'il a appris.

2. Comportement + epsilon-greedy
Elle décide :
"Est-ce que je fais confiance à ce que je sais déjà ou est-ce que j'essaie quelque chose de nouveau ?


Le reward est utiliser pour mettre a jour la valeur de q-value

Deplacer le snkae:

    new_head = (x + dx, y + dy) Ex: RIGHT -> dx = +1 et UP -> dy = -1
  -Recuperer le corps actuel
    snake = [(2,1), (3,1), (4,1)]
  -Enlever la queue
    on retire le dernier eleemnt
  -Ajouter la nouvelle tete devant
Donc new_snake = [new_head] + snake[:-1] 
snake[:-1] = prendre tout les elements auf le dernier 
Ex: snake = [A, B, C, D] alors snake[:-1] = [A, B, C] -> D(la queue) est supprimee
